# Linear

Site institucional da Linear, empresa B2B de inteligência industrial. Página estática em HTML, CSS e JavaScript, sem etapa de build.

## Executar localmente

Na pasta do projeto, rode `python -m http.server 8000` e abra `http://localhost:8000`. Os caminhos dos arquivos são relativos para também funcionar em uma publicação do GitHub Pages no subcaminho `/linearpage/`.

## Conteúdo e contato

Os dados do painel são demonstrativos. O botão de contato abre um rascunho de e-mail sem destinatário até que seja definido um endereço corporativo; ele não envia informações.
